# Agent Entry Point

- 사용자 요청을 우선함.
- 작업 범위·사용자 변경 보호·자율 진행·질문 기준은 [workflow.md](docs/agents/workflow.md)를 따름.
- 검증과 완료 판정은 [testing.md](docs/agents/testing.md), 커밋·push는 [git.md](docs/agents/git.md)를 따름.
- 리뷰 요청은 [review.md](docs/agents/review.md)를 따름. 수정 요청이 없는 리뷰는 읽기 전용임.
- [문서 인덱스](docs/agents/index.md)에서 현재 작업에 필요한 문서와 항목을 선택함. 관련 없는 문서 전체 preload를 피함.
- 화면·사용자 흐름은 페이지 명세, 코드 배치는 아키텍처, 서버 연동은 계약 문서를 기준으로 함. 문서별 담당 범위와 충돌 처리 기준은 인덱스를 따름.
